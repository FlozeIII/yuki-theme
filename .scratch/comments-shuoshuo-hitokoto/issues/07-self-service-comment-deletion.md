# 07: 访客删除自己的评论

**What to build:** 访客提交评论后收到一封带链接的邮件。打开链接看到一个确认页，确认之后那条评论被删掉。链接一次性、会过期、只对那一条评论有效，全程不需要注册账号。

打开链接先到确认页而不是直接删除，这一条是必要的：邮件客户端和聊天软件会预取链接，直接删除会在用户还没看到邮件时就把评论删掉。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 评论提交成功后发出通知邮件，正文里含一条删除链接
- [ ] 打开链接看到确认页，而不是直接执行删除
- [ ] 确认之后评论被移除，站点上不再可见
- [ ] 同一条链接第二次使用无效
- [ ] 过期的链接无效
- [ ] 一条评论的删除链接不能用来删除另一条评论
- [ ] 不带有效令牌的请求无法通过这个路径删除评论
- [ ] 仅预取链接（不点确认）不会导致评论被删
- [ ] 全程不要求注册或登录
- [ ] 删除后不留可见的空壳
