# 04: 说说的承载体配置与主列表排除

**What to build:** 站点所有者可以在自定义器里指定哪个分类承载**说说**。被指定分类里的文章不出现在首页与博客归档，但那个分类自己的归档页照常列出它们。分类不存在、被删或未配置时，功能安静地不生效——不留空白、不报错。

配置必须存**分类标识**而不是 slug，否则用户改名或换 slug 就失效（见 ADR 0001 的影响一节）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 自定义器里可以选一个分类作为说说的承载体
- [ ] 承载体分类里的文章不出现在首页列表
- [ ] 承载体分类里的文章不出现在博客归档（含分页的后续页）
- [ ] 承载体分类自己的归档页正常列出这些文章
- [ ] 未配置承载体时，一切行为与改动前一致，页面既不空白也不报错
- [ ] 承载体分类被删除后，站点不报错、不空白，行为退回「未配置」
- [ ] 承载体分类改名或更换 slug 后，配置仍然有效
- [ ] 主题激活时，若默认承载体分类不存在则创建它
- [ ] 其他分类、标签、日期归档的列表不受影响
