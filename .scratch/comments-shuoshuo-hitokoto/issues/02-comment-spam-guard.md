# 02: 评论防垃圾

**What to build:** 访客正常填表提交的评论，行为与改动前完全一致。而填了那个看不见的字段、或者页面刚加载就瞬间提交的提交，会被当作垃圾挡在**入库之前**——站点上不出现它，待审队列里也没有它。

蜜罐字段的设计要点：它必须是正常访客不会碰、密码管理器也不会自动填充的那种。时间戳令牌必须带本站签名，否则被随意填一个值就能绕过。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 评论表单里存在蜜罐字段，但它不出现在任何面向访客的输出中（评论列表、feed 里都没有）
- [ ] 蜜罐字段被填充时，提交不产生任何评论
- [ ] 页面渲染到提交之间短于 3 秒时，提交不产生任何评论
- [ ] 时间戳令牌带本站签名；被篡改或凭空伪造的值会被判为无效
- [ ] 被挡下的提交不进入待审队列
- [ ] 正常填写的提交，结果与改动前一致（该待审的待审，该发布的发布）
- [ ] 用密码管理器自动填充整个表单后提交，不会被误判
