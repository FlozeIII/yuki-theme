# 01: 本地测试基建（邮件捕获 + 上游 stub）

**What to build:** 本地验证环境具备两个观察点：所有发出的邮件被记录到文件，供测试取出正文；一言的上游可以被指向一个本地 stub，并能数出被命中的次数，也能被切换成故障状态。这是纯粹的测试基建，不改变主题对外的任何接口或行为。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 提交一条评论后，邮件捕获文件里出现那封通知邮件，正文可读、其中的链接完整未被截断
- [ ] 邮件捕获是本地环境的设施，不是主题的一部分——主题未启用时它同样工作
- [ ] 上游 stub 能返回一个可控的响应体
- [ ] 上游 stub 能被切换成 500，也能被整个停掉
- [ ] 能读出 stub 被请求的次数
- [ ] 主题代码里没有为测试而存在的分支、开关或钩子
