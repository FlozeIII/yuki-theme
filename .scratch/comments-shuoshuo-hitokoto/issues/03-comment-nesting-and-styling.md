# 03: 评论区的层级与样式

**What to build:** 评论区看起来是主题的一部分，而不是一块外来的东西。回复最多嵌套两层，更深的回复被压平到第二层而不是继续缩进；评论列表、表单、输入框、按钮全部改用主题的设计 token，深色模式下配色正确。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 三层以上的回复链，最深的回复渲染在第二层的位置，缩进不再继续增加
- [ ] 每一层仍能看出谁在回复谁，不靠缩进也知道层级
- [ ] 评论列表、表单、按钮使用主题的 CSS 变量，评论区里不出现硬编码色值
- [ ] 深色模式下评论区配色正确、正文对比度可读
- [ ] 窄屏下评论不因为缩进而被挤成一条缝
- [ ] 评论的既有行为不变（列表、回复、表单提交的结果与改动前一致）
