# 06: 评论点赞

**What to build:** 访客能给一条评论点赞，看到每条评论的计数，也能看出自己点过哪些；再点一次取消。同一个访客对同一条评论只计一次。整个过程不刷新页面。

计数存在评论上。识别访客用站点 cookie——这挡得住手滑和刷新，挡不住刻意清 cookie，对个人博客的量级够用，因此不引入账号，也不把 IP 存库。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 点赞后计数加一，页面不刷新
- [ ] 再点一次取消点赞，计数减一
- [ ] 同一访客重复点赞不会让计数继续增加
- [ ] 页面重新加载后，已点赞的状态仍然显示正确
- [ ] 计数不因为刷新或重新访问而失真
- [ ] 点赞控件使用主题的设计 token，深色模式与窄屏下表现正确
- [ ] 浏览器禁用 JS 时，页面不因此报错或残缺
