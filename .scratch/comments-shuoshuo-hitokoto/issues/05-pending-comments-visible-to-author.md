# 05: 待审评论对本人可见

**What to build:** 访客提交评论后看到明确的状态提示——已收到、正在等待审核——而不是页面静默刷新、让他不知道成没成。带同一身份再次访问时，他能看见自己那条还在待审的评论；别的访客看不到。

不新建身份机制，复用 WordPress 原生的匿名评论身份。提示的措辞不能承诺「已发布」。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [x] 提交后页面上出现明确的待审提示
- [x] 提示不承诺评论已经公开可见
- [x] 提交者带同一身份再次访问时，能看到自己那条待审评论
- [x] 其他访客访问同一页面时看不到那条待审评论
- [x] 评论被批准后，提示与可见性回到正常状态
- [x] 被 02 判为垃圾的提交不产生任何待审提示
- [x] 未登录访客的路径全程可用，不要求注册或登录

## Comments

验证方式：`node tests/bin/verify-comment-pending.mjs` —— **33/33 通过**。

### 主题只加了一句提示，可见性是核心本来就有的

写之前我打算加一个 `comments_template_query_args` 过滤器，把 cookie 里的邮箱塞进
`include_unapproved`，因为「再次访问还能看到自己那条」听起来得主题自己补。

**是测试的红清单把这个假设掀了**：`带同一身份能看到自己那条待审评论` 那一栏是**绿的**。
读源码确认——`wp_get_unapproved_comment_author_email()`（`wp-includes/comment.php:2095`）
在没有跳转参数时会**退回读评论者 cookie**（`:2108-2111`），`comments_template()` 拿它去填
`include_unapproved`。所以可见性整件事是核心做的。

按原计划写的话会多出一段复制核心行为的代码，而且**它会一直是绿的、谁也看不出多余**。
这是本主题第一次靠「先让测试红、再看哪条绿得可疑」而不是「先写后验」避免的浪费。

主题补的只有 `comments.php` 里那句提示。它数的是**已经在页面上的**那几条待审评论
（`$wp_query->comments`），不是另查一次库——所以提示永远不可能比列表多显示出什么，
「别的访客看不到」是设计自带的结果，不是靠额外判断挡出来的。

### 那句话的措辞

「你有 N 条评论正在等待审核，通过之后才会公开显示。」——只说在等审核，不承诺已公开。
用 `%s` 而不是 `%d` 接 `number_format_i18n()`：后者返回的是「1,234」这样的**字符串**，
交给 `%d` 会被强转成 1，一千多条会显示成「你有 1 条」。

### 变异验证

| 变异 | 结果 |
| --- | --- |
| 去掉循环里的邮箱比对（外层守卫还在） | **33/33，没红** —— 这是一个**等价变异** |
| 不分身份地数全站待审（改用 `get_comments` 直接查） | 3 条变红，含「陌生人看不到待审提示」 |

第一条要说清楚：它没红是**对的**，不是测试漏了。外层 `'' !== $yuki_viewer_email` 那道守卫
已经拦住了陌生人，去掉内层比对在核心当前行为下不产生任何可观察差异（`include_unapproved`
只会把**本人**的待审评论放进结果）。我最初以为这暴露了测试的空洞，核过之后确认是等价变异。
第二条才是有意义的那个：它证明「提示不泄露给别人」这条断言确实是承重的。

### 一处并发留下的抖动，以及它的边界

验收一开始**约每 7 次红一次**，抓到的那次只有一条：
`批准后评论照常可见`——而 `批准成功` 是绿的，即评论确实批了、紧接着那次渲染里却不在。

原因：测试原本借 `wp-probe.php site-info` 返回的「最新一篇允许评论的文章」。那个查询在多会话
共用一台站点时会指向**别的会话正在用的造数文章**，而它们的收尾会把它删掉——删在这一轮中间，
请求就打到 404 上，一批断言以「东西不存在」的形式红，看着像我的代码坏了。

改成自己建一篇（标题里刻意不含 `YUKI-TEST` 这类子串，免得被谁按关键字搜出来连坐）之后，
**连跑 12 次全绿**。这个证据是**倾向性而非结论性**的（若失败率真是 1/7，12 次全绿的概率约
16%），所以那条断言现在会自报「那条评论此刻什么状态」和页面上的评论条数——
万一再犯，下一次就能直接读出是没渲染还是被删了。

顺带按同一个思路改了造数脚本的清理：它原先按共用标记**全删**，等于同一时刻另一个会话也在跑
同一个脚本时，先收尾的会把对方正在用的评论删掉。现在只清「够老」的（默认 120 秒），代价是
清理滞后一轮。
