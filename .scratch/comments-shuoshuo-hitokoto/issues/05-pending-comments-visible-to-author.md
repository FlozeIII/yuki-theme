# 05: 待审评论对本人可见

**What to build:** 访客提交评论后看到明确的状态提示——已收到、正在等待审核——而不是页面静默刷新、让他不知道成没成。带同一身份再次访问时，他能看见自己那条还在待审的评论；别的访客看不到。

不新建身份机制，复用 WordPress 原生的匿名评论身份。提示的措辞不能承诺「已发布」。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 提交后页面上出现明确的待审提示
- [ ] 提示不承诺评论已经公开可见
- [ ] 提交者带同一身份再次访问时，能看到自己那条待审评论
- [ ] 其他访客访问同一页面时看不到那条待审评论
- [ ] 评论被批准后，提示与可见性回到正常状态
- [ ] 被 02 判为垃圾的提交不产生任何待审提示
- [ ] 未登录访客的路径全程可用，不要求注册或登录
