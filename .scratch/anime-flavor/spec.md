# 二次元成分

Status: ready-for-agent
Type: spec

## Problem Statement

主题的「二次元」目前主要靠堇紫/暖白、圆点纹理、柔和卡片框与太阳/月亮开关撑着；空状态与 404
仍是纯文字，缺一个能让人记住的角色与一点轻的语气。

## Solution

分四批加，始终守住**极简线**：气氛不盖过可读性，装饰不进入正文阅读路径。

1. **雪兔 + 微文案**：原创内联 SVG 的白色雪兔，出现在 404、空状态与首页 hero；空状态文案
   带一点轻的语气。
2. **贴纸/气泡**：分类徽章变贴纸（轻微旋转/虚线边），空状态用对话气泡。
3. **季节点缀色**：按月份自动切一枚**只用于装饰**的强调色（春樱粉/夏天蓝/秋琥珀/冬雪紫）；
   正文、链接、按钮不变。
4. **hero 动效**：6–8 个纯 CSS 樱瓣/星光，`prefers-reduced-motion` 下完全停；不铺到全站。

每一批单独验收，一批不绿不开下一批。

## User Stories

1. 作为访客，我希望 404 与空状态不再像模板默认页，有一个记得住的小角色。
2. 作为访客，我希望这个角色不挡正文、不影响阅读。
3. 作为站主，我希望角色的素材是自己仓库里的原创 SVG，不依赖外部图片或版权不明的素材。
4. 作为设计者，我希望颜色只从现有 token 里取，不新增调色板。

## Implementation Decisions

### 雪兔（第一批）

- 新模板片段 `template-parts/mascot.php`：内联 SVG，参数 `size`（`sm` / `lg`）与 `class`。
  `aria-hidden="true"`、`focusable="false"`——它是装饰，语义由旁边的文字承担。
- 造型：白色圆润身体、长耳、两点墨色眼睛、堇紫围巾；颜色只用白、墨色、`--yuki-primary`、
  `--yuki-border`，不引外部图片。
- 尺寸：`lg` 112px（hero/404），`sm` 64px（空状态）；640px 以下 `lg` 缩到 88px。
- 出现位置：首页 hero（标题右侧，窄屏落到标题下方）、404、空归档、空搜索、首页无文章。
  **不进侧栏、不进导航、不进正文。**

### 微文案（第一批）

- 404：「雪兔在雪地里找了半天，也没找到这一页。」+ 原有解释与搜索。
- 空归档：「雪兔翻遍了这一栏，还没有文章。」
- 空搜索：「雪兔竖起耳朵听了半天，没有找到匹配的文章。换个关键词试试。」
- 首页无文章：「雪兔把院子扫干净了——还没有文章，去后台发布第一篇吧。」
- 语气轻，但不卖萌到影响理解；全部走 `__()`。

### 后续批次（尚未实现）

- 贴纸/气泡：分类徽章轻微旋转/虚线边；空状态文案用对话气泡包一层。不改列表版式。
- 季节点缀色：按月份自动，只加一枚装饰用强调色；不覆盖主色，不改正文/按钮。
- hero 动效：纯 CSS、少量元素、reduced-motion 全停；不做光标与页面转场。

### 明确不做的

- 不把动漫角色放进正文、导航或主题开关。
- 不使用外部图片、字体或版权不明的素材。
- 不让季节色改变链接/按钮/正文颜色。
- 不做全站飘落、定制光标、页面转场。

## Testing Decisions

### Seam

HTTP + 静态：页面里能看到 `/看不到` 角色与文案；SVG 是内联的、没有外部引用。hero 的尺寸与
640px 不横向滚动用真浏览器量。

### 要测的模块

- 首页 hero：`.yuki-hero` 里有 `.yuki-mascot`，`aria-hidden="true"`。
- 404、空归档、空搜索：有 mascot 与新文案。
- 首页无文章：模板源码里有 mascot（站点有内容，不为此清空全站）。
- SVG：内联，不含 `http` 外链，颜色只用白/墨/`--yuki-primary`/`--yuki-border`。
- 640px 下 hero 不横向滚动；深色下 mascot 仍有尺寸。

### 明确不测什么

- 角色造型的主观好看程度。
- 后续三批（贴纸、季节、动效）——各自批次再测。

## Out of Scope

- 贴纸/气泡、季节色、hero 动效（后续批次）。
- 侧栏、导航、主题开关里的角色。
- 外部素材与字体。
