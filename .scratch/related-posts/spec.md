# 关联文章

Status: ready-for-agent
Type: spec

## Problem Statement

一篇文章读完之后，读者只有上下篇这一条**线性**出口。主题已经有分类与标签，却没有用它们做一次
「横向」的推荐：读到一篇讲同一类事的文章，找不到另外几篇。

首页的文章列表承担了「最新」的浏览，但读者已经在一篇文章里时，不该被迫回到首页再找。

## Solution

在文章正文与上下篇之后、评论之前，放一小块**关联文章**：同分类优先，不足用同标签补，最多 3 篇，
排除当前文章。没有关联时整段不输出；说说文章不显示。

查询与渲染放新文件，`single.php` 只加一处模板调用；样式复用现有 token，不加缩略图。

## User Stories

1. 作为读者，我希望读完一篇后能看到几篇同分类的文章，这样我能顺着主题继续读。
2. 作为读者，我希望同分类不够时用同标签补上，而不是只剩一两篇。
3. 作为读者，我希望最多看到 3 篇，不要变成第二份文章列表。
4. 作为读者，我希望当前这篇不要出现在关联里。
5. 作为读者，我希望没有关联时页面不要多出一个空区块。
6. 作为作者，我希望关联由现有分类/标签决定，不需要维护一份手工推荐列表。
7. 作为作者，我希望说说文章不显示关联——短碎片不需要延伸阅读。
8. 作为读者，我希望关联出现在上下篇之后、评论之前，保持「先顺着读，再横向看」的顺序。
9. 作为设计者，我希望这块只用现有 token，不引入缩略图与新颜色。

## Implementation Decisions

### 关联规则

- 只对 `post` 类型、已发布的文章生效；页面、说说与别的类型不显示。
- 当前文章在**说说的承载分类**里时直接返回空（`yuki_shuoshuo_category_id()`）。
- **第一轮**：同分类（`wp_get_post_categories`），按日期倒序，最多 3 篇。
- **第二轮**：第一轮不足 3 篇时，用当前文章的标签（`wp_get_post_tags`）补足剩余数量；
  排除当前文章与第一轮已选中的文章。
- 关联结果**排除说说的承载分类**，避免短说说混进关联。
- 固定 `orderby=date`、`order=DESC`、`no_found_rows=true`；不随机，方便验收。
- 没有任何分类与标签时返回空；**不回退到最新文章**。

### 位置与标记

- `single.php` 在 `.yuki-post-nav` 之后、`comments_template()` 之前调用
  `get_template_part( 'template-parts/related-posts' )`。
- 模板片段自己查询；空时直接 `return`，不输出任何标记。
- 结构：`<nav class="yuki-related" aria-label="相关文章">` → `<h2>` → `<ul>` → 每项一个链接，
  链接里是标题与日期。**不加缩略图**，与首页文章列表区分。
- 文案「相关文章」走 `__()`；heading 与 aria-label 共用同一条 msgid。

### 视觉

- 段落顶部一条 `--yuki-border` 分隔线，与标签区、上下篇同一节奏。
- 标题 18px / 600；列表项 15px、日期 12px 用 `--yuki-muted-foreground`；hover 用主色。
- 不使用阴影、卡片底或新颜色；深色模式的 hover 沿用 `.dark` 下的主色。

### 明确不做的

- 不做后台配置（数量、规则、手工推荐）。
- 不做缩略图、摘要、分类徽章。
- 不做随机或按热度排序——没有数据支撑，也无法稳定验收。
- 不做「暂无相关文章」占位。
- 不把关联扩展到页面与说说。

## Testing Decisions

### Seam

HTTP 就够：请求文章页，HTML 里能数出条数、顺序与排除项。样式用 `theme-css.mjs` 做静态断言。
不新增浏览器观察点。

### 要测的模块

- 当前文章页：`.yuki-related` 存在，正好 3 条，顺序与预期一致。
- 当前文章自身不在关联里。
- 同分类的两篇在前，同标签的一篇补足第三位。
- 没有关联的文章页：整段不输出。
- 说说文章页：整段不输出，即便其分类下还有别的说说。
- 关联区块在 `.yuki-post-nav` 之后、`.yuki-comments` 之前。
- 样式只用已定义 token，无硬编码颜色。

### 明确不测什么

- 分类/标签的权重或相关性算法——这是 WordPress 查询的直接结果。
- 缩略图、摘要——不在这一版。
- 随机性——刻意不做。

## Out of Scope

- 后台设置、手工推荐、阅读量/热度。
- 页面与说说的关联。
- 缩略图与摘要版式。
- 多语言之外的展示变体。

## Further Notes

- **共享文件**：`functions.php`（显式 `require_once`）、`style.css`、`languages/yuki.pot`。开工前在
  `.scratch/holds.md` 挂行，提交后删掉。
- 新文件优先：`inc/related-posts.php` 放查询，`template-parts/related-posts.php` 放渲染；
  `single.php` 只加一处调用。
- 文案「相关文章」需要重建 `yuki.pot`：按 `AGENTS.md` 第 5 条，从 HEAD + 本件改过的文件生成。
- 后续若要「按标签相似度」或「排除同分类的说说」，在这一件之外另立。
