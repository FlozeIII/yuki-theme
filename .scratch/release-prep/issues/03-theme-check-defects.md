# 03: 主题里 Theme Check 报出来的两处真缺陷

**What to build:** 两处使用者能撞上的缺陷。它们不是为过审而做的仪式，是体检筛出来的真东西——也是这一件里唯一动到主题代码的地方。

**其一**：文章用分页标记切开时，读者拿不到指向后续页的链接，**第二页够不着**。这是官方检查报的 REQUIRED 项。

**其二**：评论删除的确认页硬写了一个 `<title>`，而主题明明已经声明了标题由核心统一产出。结果是那一页绕过了主题自己的规则——标题该在哪儿生成，从此有了两处答案。

**Blocked by:** 无（可以立刻开始）

**Status:** ready-for-agent

- [ ] 一篇用分页标记切开的文章，页面上出现指向后续页的链接，点得进去
- [ ] 没有分页标记的普通文章不会因此多出一块空的翻页区
- [ ] 打开评论删除确认页时，标题仍然正确显示
- [ ] 确认页产出的 HTML 里**只有一个 `<title>`**
- [ ] 主题其余页面的标题行为不变
