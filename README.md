# Yuki — 极简 × 二次元 WordPress 主题

暖白底色 + 柔和堇紫主色的极简博客主题：浅色/深色模式、纵向文章列表、文章页侧边栏、说说、评论增强、
图片灯箱、雪兔与季节点缀，以及自托管发版。classic theme，无构建步骤，编辑器与前台共用同一份样式。

当前版本 **1.2.0**，以 **GPL-2.0-or-later** 自托管分发（见下方「许可」）。

## 安装

1. 将发行包（如 `yuki-1.2.0.zip`）上传到 WordPress 后台 → 外观 → 主题 → 安装主题 → 上传主题；
   也可解压到 `wp-content/themes/`，得到 `yuki/` 目录。
2. WordPress 后台 → 外观 → 主题 → 启用 **Yuki**。
3. 外观 → 菜单：创建菜单并指定到「主导航」位置。
4. 外观 → 自定义 → **Yuki 页脚设置**：填写 ICP 备案号 / 公安备案号（留空则显示占位）。
5. 外观 → 自定义 → **Yuki 头像设置**：Gravatar 在境内访问不了，国内主机请改选 Cravatar 或自填镜像地址。

## 从源码打包

需要 Node.js 22.2+ 和 Git，无需 WP-CLI 或安装 npm 依赖。在仓库内运行：

```bash
node tests/bin/package-theme.mjs
```

默认输出 `.scratch/release-prep/yuki.zip`，也可指定输出文件：

```bash
node tests/bin/package-theme.mjs /path/to/yuki.zip
```

要打某个标签或提交，而不是当前 `HEAD`，加 `--rev`：

```bash
node tests/bin/package-theme.mjs --rev v1.2.0 /path/to/yuki.zip
```

打包读取**指定提交**（默认 `HEAD`）中的主题文件与 `.distignore`，排除开发、验证与协作文档，
解开后顶层只有 `yuki/`。先提交要发布的改动；未提交修改和未跟踪文件不会进入包。`--rev` 接受标签
或提交号，打包前会先解析成提交；找不到时命令报错停下，不会退回 `HEAD`。命令会打印解析后的提交号。

`.distignore` 是唯一的排除清单，只支持从主题根目录起算的字面路径（目录可带末尾 `/`）、空行与
`#` 注释；通配、取反和转义语法会报错停下。

包内容的验收也可直接用 Node 运行，不需要 WordPress 或 WP-CLI：

```bash
node tests/bin/verify-package.mjs
```

## 重拍首页截图

顶层的 `screenshot.png` 是主题在「外观 → 主题」里的那张脸：真实渲染出来的首页，浅色形态，
1200×900（官方要求是「不大于 1200×900」且 4:3）。它随仓库提交，正常发布不需要重拍；要换一张时
先让本地站跑起来，再按顺序跑：

```bash
# 这台机器上没有系统级的 php，用便携版的全路径（见 tests/README.md 的环境变量表）
"C:/Users/Floze/wp-dev/tools/php/php.exe" tests/bin/screenshot-fixtures.php "C:/Users/Floze/wp-dev/wordpress"
node tests/bin/make-screenshot.mjs
```

第一条往本地站放进 6 篇标题与缩略图都像正常博客的演示文章，并**置顶**占住首页第一屏——这个本地站
同时开着别的会话，它们的造数文章日期更新，不置顶就会插到演示文章中间（见脚本头）。演示文章都带
`_yuki_screenshot_demo` 标记，重跑会先撤掉上一轮，可反复执行。

截图走无头浏览器（CDP），在**设好视口之后**产出，不是 `--screenshot --window-size` 那类先按更宽
布局渲染再裁剪的老办法。拍之前它先确认首页模板在、文章够数、视口里的缩略图都加载完了，任一不成立
就报错停下、不覆盖已有的图；拍完会把第一屏的标题打出来。

```bash
node tests/bin/verify-screenshot.mjs
```

## 特性

### 外观与布局

- **浅色 / 深色**：头部滑动开关，偏好记忆在 localStorage，跟随系统偏好初始化（头部内联脚本防闪烁）。
- **自定义背景**：外观 → 自定义 → 背景图像，可上传全站背景图与背景色；有图时主题加一层跟随
  深浅色的蒙层，强度在同一节的滑杆里调（默认 80）。只设背景色时不加蒙层。
- **纵向文章列表**：首页单列陈列，左小缩略图 + 标题 / 摘要 / 日期 / 分类。
- **文章页两栏**：正文 + 300px 侧栏；移动端自动堆叠。单篇主列 724px，宽对齐在那类布局里退化为
  正文列宽，只有单栏页面才会放宽到 1120px（`DESIGN.md` 的「布局」一节）。
- **动效收敛**：`prefers-reduced-motion` 只停运动、保留颜色；列表与上下篇 hover 1px 浮起；
  列表 / 上下篇 / 关联 / 标签共用同一枚焦点环。
- **视觉与 token 只有一个来源**：`DESIGN.md` + `style.css`，不引入 `theme.json`（ADR 0003）。

### 二次元点缀

- **雪兔**：原创内联 SVG，出现在首页 hero、404 与空状态；空状态文案带一点雪兔语气。
- **分类贴纸与对话气泡**：分类徽章是轻微旋转的贴纸（虚线边 + 半透明胶带），空状态文案装在朝上的气泡里。
- **季节点缀色**：按站点时区月份自动切换——春樱粉、夏天蓝、秋琥珀、冬雪紫；只染雪兔与贴纸胶带，
  正文、链接、按钮与主题开关仍是主色。
- **hero 花瓣**：7 枚纯 CSS 樱瓣/星光，颜色跟季节走；`prefers-reduced-motion` 下整层隐藏。
- **克制**：装饰不进正文、导航与主题开关；正文阅读路径不受影响。

### 内容

- **说说**：独立分类归档，紧凑版式；归档顶部有写作框，有 `publish_posts` 权限的作者可以直接发布，
  失败保留正文。
- **关联文章**：文章末尾，同分类优先、同标签补足，最多 3 篇；无关联不占位，说说文章不显示。
- **图片灯箱**：正文与说说里的图片可点开看大图，显示页面能提供的最大图与图注；Esc / 遮罩 / 关闭按钮
  都能关，关闭后焦点回到触发图，完整键盘可用。
- **一言**：侧边栏露出一句随机的话，取自 [hitokoto.cn](https://hitokoto.cn/)。**由服务端取回并缓存
  一小时**，访客的浏览器不直接请求第三方；上游超时、报错或返回无法解析的内容时，显示主题自带的一句
  兜底。不想用它，往侧边栏放一个自己的小工具即可（见下一条）。
- **侧边栏可配**：在「外观 → 小工具 → 文章侧边栏」放入任意小工具即接管，一个都不放则用内置默认
  （作者卡、一言、分类统计、标签云、热门文章）。

### 评论

- **防垃圾**：隐藏蜜罐 + 时间戳令牌；页面渲染到提交不足 3 秒会被挡下并给一句能照做的话，
  令牌超过一周则失效。
- **待审评论对本人可见**；嵌套深度受限，深层回复压到第二层。
- **点赞**：每条评论一个控件，按访客 cookie 记状态；同一 IP 每分钟最多 60 次。
- **访客删掉自己写错的评论**：通过邮件里的链接，不需要注册或登录。
- **提交不刷新**：新评论就地出现；回复落在被回复的那条下面，表单回到底部。

### 氛围与工具

- **搜索**：头部放大镜展开居中浮层，背景模糊，Esc / 点遮罩 / 再点按钮关闭。
- **主题开关 / 头像镜像 / 备案号**：分别记忆深浅色偏好、把头像源换成境内可达的 Cravatar 或自填镜像、
  把 ICP / 公安备案号链到查询站点。
- **编辑器**：直接使用同一份 `style.css`，字体、引用、代码块、图片圆角与前台一致，画布约 720px。
- **国际化**：文案统一走 `yuki` 文本域，`languages/yuki.pot` 可直接交给译者。翻译文件放
  `wp-content/languages/themes/yuki-{locale}.l10n.php`（或 `.mo`）。
- **无构建步骤，开箱即用。** 唯一的外部依赖是一言：只有它需要联网（服务端取回、缓存一小时），
  连不上时用主题自带的句子顶上，页面照常完整——它是「不自足功能」，降级是它的一部分。
